BirdCam Flowchart App (openSUSE)

Hello! Thanks for using the BirdCam Flowchart App.

To run this application on openSUSE, you must first install a required system library (graphviz) that is needed to generate flowcharts.

Instructions

Run the Installer:

Double-click the install.sh file and choose "Run in Konsole" or "Run in Terminal".

(Alternatively, open a terminal in this folder and type: ./install.sh)

Wait for Installation:

The script will ask for your password to install graphviz.

Wait for it to show "Installation complete."

Run the App:

You can now run the application.

Double-click the BirdCam_suse file to start.

That's it!
